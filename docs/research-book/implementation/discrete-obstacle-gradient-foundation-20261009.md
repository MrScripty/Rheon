## Owned-state interface and restricted support

`ObstacleVelocityGradient<'s,'g>` will borrow one immutable `ObstacleFlowState<'g>` for its lifetime. It will own only a bounded vector of immutable requested derivative rows. There is no raw-field production constructor, generated velocity, physical-input default, new wall observation or accepted state mutation. Physical declarations and Unknown/caller-declared errors remain accessible through the borrowed state. Its qualification remains `Unqualified`. The operator represents a requested local row collection, not a complete global gradient, strain energy, traction or physical evolution. Repeated requests are an explicitly allowed multiset: they repeat a row/weight in the finite pairing, without claiming global quadrature completeness.

A request is one of: cell-normal derivative `Normal{axis,cell}`, ordered cross derivative `Cross{component,derivative,edge,quadrant}`, or `CoarseFine` (explicitly refused). Each request supplies an index on the existing uniform retained grid; cross axes must differ and quadrant must be0..3 in the ascending-axis edge frame. Normal requests require a fluid cell. Cross requests require an internal grid edge, the requested quadrant to be fluid, and either four fluid quadrants (interior) or two adjacent fluid quadrants (flat obstacle). Three-fluid-quadrant corner queries, outer-edge cross derivatives, zero/one fluid quadrants, diagonal two-quadrant patterns, solid sectors and invalid indices refuse construction. No corner hinge, outer gradient extension, coarse–fine interpolation or omitted unsupported row is filled implicitly. Normal rows on fluid cells at the outer/solid wall are supported with stationary normal traces. The full-state owner already enforces these traces; no inhomogeneous wall data can be injected through this interface.

Every admitted requested row is retained, including an identically zero row. A row records component/derivative, cell or edge coordinates, actual sector, positive volume weight, support classification, and its two geometric endpoint descriptions. Each endpoint records its actual represented world position, coefficient, and either a source full-face velocity index or an explicitly eliminated stationary trace. Normal endpoints on blocked faces are stationary-solid traces; outer normal faces are stationary-outer traces. A cross derivative tangent to a flat obstacle's normal component is explicitly a stationary-solid derivative with a zero row. Its endpoint positions are on the physical flat wall, not snapped cell centers. The normal derivative of a tangential component uses the actual center sample and actual wall trace. Endpoints are ordered lower-to-upper in the derivative direction so separation is positive on either reflected wall side; the active coefficient sign follows that orientation. Endpoint metadata explains every eliminated coefficient; sparse velocity terms include only active stored face sources.

## Reconstruction and affine consistency

For a fluid cell and axis a, the normal row is `(u_a(x_plus)-u_a(x_minus))/(x_plus[a]-x_minus[a])`, with face-plane endpoints and stationary normal trace elimination. Its weight is the retained cell fluid volume V (not2V; this interface stores a directed gradient, not the former symmetric normal strain metric).

At an interior a–b grid edge, the ordered cross row `partial_b u_a` uses the two staggered u_a samples at represented b cell centers on opposite sides: `(U_plus-U_minus)/(center_plus-center_minus)`. Each fluid-sector request has weight `abs(center_a-plane_a)*abs(center_b-plane_b)*represented_width_c`. Endpoints remain at the actual a face-plane, b cell-center and c cell-center coordinates. The reverse derivative is a separate requested row. There is no cross-component averaging.

At a flat no-slip wall normal to b, the supported derivative `partial_b u_a` (a tangential) is `(U-0)/(center_b-wall_b)` with its signed represented distance. The reverse derivative `partial_a u_b` is zero because the stationary normal trace u_b is identically0 along that flat wall; its two endpoints lie on the wall at the two represented a centers. This is a local P1 wall-ray/trace reconstruction, not a physical load certificate or an exact derivative for arbitrary nonaffine data. Each actual fluid-sector volume is retained separately. Summed wall-ray quadratic coefficient is `sum(v_sector)/delta^2`; identifying it with a geometric `A/delta` additionally requires exact product-volume premises. Stored rounded measures alone do not prove that area equality.

For any admitted two-endpoint row with endpoint direction b, nonzero exact-real represented separation d, and supplied endpoint values from `u_a(x)=c+sum_j M_aj*x_j`, exact-real evaluation equals M_ab when all other endpoint coordinates match. Eliminated traces require compatibility with that affine field at the recorded trace positions. For a flat normal trace, affine compatibility at both endpoints implies the tangential derivative0. An arbitrary globally nonzero affine field is incompatible with stationary no-slip on all faces of a retained internal box; labs therefore use explicitly declared local affine patches in otherwise admissible full-face arrays and validate only the requested local stencils. They do not relabel manufactured test data as a physical solution. Compatible rigid rotation tests apply to interior local stencils only; the full directed gradient is skew, not zero. Symmetric-gradient assembly, global Korn/coercivity, pressure closure and wall force accuracy remain outside this slice.

## Exact finite work and native arithmetic

Let G contain the retained row coefficients on the existing full-face velocity space, after explicit stationary traces are eliminated, and W contain the stored positive row weights. `gather(out)` computes G u from the borrowed state. `transpose(row_test,[out_x,out_y,out_z])` computes G^T W q, using the same stored rows and weights with full-face output sizes. No mass inverse, viscosity, force sign, pressure operation or update is included. All inactive output faces stay0; normal traces have no velocity adjoint column. In exact real arithmetic the finite identity is `sum_r w_r*(G u)_r*q_r = sum_f u_f*(G^T W q)_f`. If a future interface introduces nonstationary independent traces, their transpose/work terms must be added explicitly; this stationary interface cannot authorize that extension.

A diagnostic method computes the row pairing directly, assembles G^T W q into caller-supplied full-face scratch using the public transpose operation, and independently sums the RHS from those actual full-face results. It records their nearest-rounded defect. It does not interpret this defect as an IEEE enclosure, accepted tolerance or physical certificate. Input/output shape and finite normal-or-zero row-test values are checked before writing. Arithmetic uses existing checked finite/underflow-refusing primitives; on arithmetic failure or cancellation caller output may be partially written, but the immutable state/operator never mutate. Actions allocate no heap memory. Stored derivative coefficients are ordinary nearest-rounded binary64. The exact-real affine quotient leaf uses division by the represented nonzero separation; transferring it to stored rows additionally requires an explicit exact-reciprocal coefficient premise. The finite transpose-work identity applies to any coefficients, including the same stored rounded coefficients, interpreted as reals. These statements do not assert exact f64 evaluation.

The constructor performs count/size/cap checks, validates every requested stencil before reserving rows, then checks actual Vec capacity and all generated coefficients/weights before returning an owner. The cap includes the borrowed state's combined geometry/owner payload once, the fixed gradient owner size, and actual row-vector capacity. It is1..16,000,000 bytes. Caller request arrays, output/test buffers, allocator overhead, stack and RSS are excluded; bounded labs separately account simultaneous managed payloads. There is no hard allocator/RSS peak promise or whole-program aggregate cap. Unsupported construction must not publish partial rows or mutate supplied state.
