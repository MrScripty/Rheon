## Frozen contract

`ObstacleFlowState<'g>` owns three full-face f64 velocity arrays and fixed-size, value-owned metadata. It borrows one immutable `StaticObstacleGeometry` for its lifetime. This avoids a self-referential geometry/operator owner and preserves Rust identity/lifetime sharing for future operators. No mutable access, replacement, accepted-commit, pressure values or step methods are exposed. It is a declared snapshot/data owner, never a claim of accepted obstacle dynamics. State qualification is forced `Unqualified`; callers cannot supply a certified/accepted flag. Geometry and view are immutable.

Admission uses exactly the existing aligned-strain geometry admission, shared via crate-private visibility only, with no behavior change: exact retained internal grid-aligned box planes with at least one fluid cell padding, no snapping or unsupported geometry extension. Full-face lengths match the borrowed pressure face space. Every value is finite normal-or-zero; outer, blocked and other inactive normal faces are exactly stationary (signed0 may be preserved). No invalid supplied face is zero-filled. Tangential no-slip solid traces and sealed free-slip outer conditions are an explicit boundary model, not inferred from sample divergence.

Required physical inputs: SI units, an explicitly selected transient incompressible Newtonian model (Navier–Stokes or unsteady Stokes), finite positive normal density and dynamic viscosity, problem evidence, boundary evidence/model, specified initial data/evidence and initial time, and explicit forcing/history evidence covering initial time through the declared frame. Explicit no forcing is a supported declaration distinct from missing forcing. No physical-input defaults or generated velocities exist. References are fixed-size `(id:u64,version:u64,sha256:[u8;32])`; id0 or all-zero digest is rejected as missing evidence. They are content-reference declarations, not authentication or independently verified physical truth. No variable strings/history buffers are retained.

Snapshot origin is either specified initial data or an imported external snapshot with additional source evidence. Initial-origin frames require time equal to initial time and generation0; an explicitly known-rest initial condition requires every velocity exactly0. Imported frames require finite nonnegative normal-or-zero time at/after initial time, with complete declared forcing-history interval; generation is a supplied sequence identity, not proof of evolution. Inputs/data are validated before owned-array allocation/publication.

Error metadata explicitly contains three componentwise face-velocity L-infinity uncertainties plus spatial, temporal, input, boundary/transfer, algebraic and roundoff contributions (all velocity-error units m/s). Each is `Unknown` or `CallerDeclaredUpperBound{nonnegative finite normal-or-zero value,evidence}`. A caller-declared0 is not a certified0. Unknown errors are admissible uncertainty; missing physical input evidence is not. The owner neither aggregates these into a physical certificate nor certifies divergence, pressure, C3 regularity, force accuracy or operator work. Pressure is explicitly unavailable.

Public construction copies caller supplied arrays into new owned storage. There is no rest/oracle fallback. Existing objects/caller arrays are unchanged on failure. The budget is1..16,000,000 bytes and cannot be raised by this API. It conservatively charges geometry retained Vec payload once, fixed owner/metadata size and actual owned velocity capacities. It excludes caller input arrays, allocator overhead, fixed codec scratch and process RSS; tests separately bound all simultaneously live fixtures. Planned sizes are checked before any allocation, actual Vec capacities before publication; allocator rounding can occur before the latter check, so no hard RSS or allocator peak guarantee is claimed.

## Checkpoint contract

A versioned binary codec streams through caller-provided `Read`/`Write`; no dependencies, hidden file paths or in-memory output copy are required. An IO failure can leave a partial caller-owned output; the state is unchanged. File atomicity/transport timeouts are caller concerns. Wire f64 values preserve exact bits; lengths/indices are u64 with checked target conversion, fixed bounded tags and refs.

Decode compares the complete supplied geometry against the wire record before velocity allocation: grid counts/origin/spacing, retained bounds, surface stamp/tolerance/vertices/triangles, fluid volumes, open areas, component count/labels. Stamp equality alone cannot bind geometry. Comparisons are exact bitwise for represented numeric data; no fingerprint collision or tolerance-based identity acceptance exists. Geometry is borrowed, not reconstructed from untrusted counts. Fixed metadata is decoded/validated; required refs, model/units/boundary/qualification/pressure/origin/error tags, chronology, full-face lengths and the combined budget are checked. Incoming lengths are compared to known admitted lengths, never used unchecked to allocate.

Only then are new face arrays allocated. Each decoded velocity is validated before publication. Truncation, wrong/unknown tags, integer/length mismatch, wrong geometry, missing evidence, illegal fields/traces, invalid metadata, or trailing bytes rejects the new object. Partial new arrays are dropped; prior state/input geometry remains unchanged. A checkpoint's stored qualification must be `Unqualified` and pressure-unavailable; restore cannot elevate either. A new state is returned only after full validation and EOF. The codec records physical declarations and uncertainty, not accepted solve scratch.
