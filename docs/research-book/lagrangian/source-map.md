## Evidence vocabulary

**Standard derivation:** textbook-level identity rederived here. **Conditional proof:** an exact-real implication under named hypotheses, not software verification. **Original exposition:** organization, calculations and pseudocode authored for this book; no scientific-priority claim. **Formal result:** only the exact existing Lean statement/source/assumptions cited by its earlier owner; no new FEM result is formalized here. **Numerical evidence:** requires a real executed run with sources, inputs, errors, environment and bounds. The new worked examples are hand calculations, not recorded executions.
