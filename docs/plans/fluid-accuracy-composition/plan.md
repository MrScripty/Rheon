## Risks, blockers and re-plan triggers

Principal risks: wall support/visibility discontinuities break an assumed energy model; variable particle volumes alter all quadrature; tiny cut cells degrade conditioning and stability; split pressure/viscosity loses free-surface traction; uniform/fixed-neighbor refinement can converge to a biased stencil; higher interface order may trade monotonicity for shape; validation thresholds may be infeasible for a selected method; receipts can add hot-loop/storage cost; graph summaries can overstate evidence.

Mitigations are bounded native oracles before integration, explicit geometry/event/work accounting, immutable method versions, bounded aggregated receipts (no per-pair logging by default), shared custody, independent review and retained failures. Hard realtime and hostile in-process plugin isolation are not promised.

Specific blocker: V1 quantitative MARIN validation needs numeric observations, sensor coordinates/areas, sample timing/filtering, gate release/time-zero and uncertainty; pressure-load comparison additionally needs a qualified traction/measurement operator. No CUDA/native product graph/new production solver was exercised by P0. No A1 input is required for reference verification or classical replacement fixtures. Exact new-proof availability is recorded in qualification, not generalized into a scientific blocker.

Re-plan when a selected boundary method fails planar isolation/work, common geometry cannot reproduce flux/traction order, graph capture requires changing numerical ordering, receipt overhead exceeds the slice budget, a provider cannot roll back hidden state, old archive compatibility changes, main modifies the D1 owners materially, or independent physical data contradicts a claimed envelope. Change the canonical decision and criteria before the next evaluation; retain original failing evidence.
