## Closed request, supplied candidate and result

The request retains immutable borrowed actual provisional f32 x/y/z faces, grid, f64 density, actual shortened dt and interval_start, PressureSettings and separate actual f32 divergence limit. It includes a declared SessionIdentity/generation and an explicit domain. Only SealedStationaryBox is admitted; free-surface, embedded-obstacle and moving-wall domain labels refuse before execution. These source tags prove consistency of supplied inputs, not authenticity or a verified accepted Session generation. Constructor validates field shape/finiteness/fixed-wall normals using the existing sealed operator, positive finite interval and density, finite nonnegative limits, positive max_iterations (the new API promises a usable native fallback), and bounded nonempty source revision. No pressure-v1 validation policy changes.

SHA256 input identity uses a fixed domain-separated projection-v1 contract/operator/gauge/SI/layout/precision identifier, count/spacing/origin, source run/revision/generation, interval_start, actual dt, density, all pressure settings, actual_divergence_limit and every provisional f32 face bit in x/y/z order, with explicit lengths. Hash actual immutable inputs; RHS is always built by the host from those inputs. Candidate headers carry exact input identity, version/operator, cell-f64-Pa and each staggered-face-f32-m/s representation (shape/layout/scalar/units), and bounded declared algorithm/version/source identity. Unknown/mismatched representation, input binding or malformed identity is a typed refusal without fallback. Metadata is declared, not observed runtime provenance.

Candidate arrays are borrowed immutable data, with no prepare/commit/abort or hidden provider state to roll back. Shape/nonfinite/fixed-wall/gauge/pressure quality/correction-witness/actual-divergence failure is a typed candidate rejection with the declared compatible native fallback. Unsupported candidate execution, runtime errors, stateful transactions, arbitrary external side effects and uncertain commits are unavailable, not tested as passing. Their full C1-B/C/R gates remain required before such invocation exists.

Use only the existing pressure dispatcher for full compensated residual/gauge/predicted-divergence gates and original numerical diagnostics. A private supplied-array bridge copies pressure into that dispatcher; its identity says supplied projection pressure witness, never model execution. Use existing correct_candidate_in_place on scratch copied from the actual immutable f32 provisional input; compare candidate velocity bits exactly against that host correction. This preserves valid signed-zero walls/interiors instead of silently substituting correct_velocity's +0 walls. This strict f32 witness admits the current discretization/order only, not arbitrary approximate reconstruction. Host recomputes actual all-cell divergence with the same separate frozen limit. Divergence-free wrong dynamics must fail the correction witness.

Every fallback discards all candidate pressure/velocity and reconstructs native pressure and correction from the identical original immutable provisional fields, dt, density, grid and settings. A pressure-dispatcher rejection that already ran fallback is retained with its actual report; do not relabel fallback output as supplied-candidate acceptance. If candidate pressure was accepted but its actual divergence fails, rerun the native path from immutable input, retaining the candidate rejection. Native/fallback failure returns its typed error and no qualified result. No compatible fallback is guessed outside the sealed domain.

Success returns an immutable pressure/velocity view borrowed from caller-owned disposable workspace with original pressure report, explicit supplied/native-baseline/native-fallback selection, declared candidate identity/rejection and measured actual divergence. The borrow prevents overwrite while used. All errors/cancellation return no qualified view; scratch may be invalid and is never accepted state. No copied accepted history or publication. Cancellation is cooperative before solve, through existing pressure solve and after qualification/before returning; no preemption or hard deadline claim for synchronous operator loops.

Preallocate and cap aggregate Vec capacities: existing ProviderWorkspace plus host RHS/divergence (two f64 cell arrays) and three f32 face witness/output arrays. Checked count/byte arithmetic, try_reserve_exact and final actual-capacity accounting. Caller inputs/candidate arrays, metadata, allocator overhead and stack are excluded explicitly; no per-attempt Vec allocation. Return typed budget/allocation errors. No process, file or runtime work.
