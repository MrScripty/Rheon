# G1 workflow custody and native inspection contract

The numerical composition owner emits a finite sealed, constant-density MAC descriptor. It describes the existing stage order, operator, SI units, layouts, geometry, pressure settings, viscosity disabled versus applied zero, data dependencies, pressure iteration loop, fallback and accepted time loop. It is not an executable graph. Family/state conversion and graph editing remain unavailable.

Each actual attempt binds run/attempt/accepted-input/attempted-generation identity, exact native input state and actual request-control digests, requested/actual interval, descriptor digest, observed provider support/prediction/qualification/fallback facts, actual combined residual threshold, pressure-call timing scope, corrected divergence, legal completed-node prefix and optional publication. Failed/cancelled attempts cannot claim publication. Candidate/accepted metrics require their actual numerical boundary. Parameters and declared recipe provenance remain distinct from observed execution and physical accuracy.

`src/recording/workflow.rs` owns additive `RCP4:` accepted controls and `RCT2:` terminal details inside the existing SQLite v1 envelope. They wrap the original bounded RCP2/RCP3 or RCT1 binary payload, without double-hex expansion, plus source binding and validated workflow facts. Existing RSC1/configured profile, old encoders/readers, field custody, resource limits and uncertain-write rules retain their meanings. A recording failure after physics commit is an explicit accepted tail, never rollback. Descriptor/summary limits and the existing 16 KiB metadata cap apply before publication.

Readers validate exact source/descriptor/interval/provider/publication association, legal node/status prefixes, increasing retained attempt IDs, immediate prior native-state digest where available and runtime-outcome consistency. Configured archive inspection also compares actual control digests against reconstructed frozen intent. Missing old workflow evidence is unavailable; corrupt/cross-linked/unknown versions are typed errors. Terminal inspection works at generation zero without an accepted row or model process.

The existing Inspector owns exact selected disk records and caches the validated attempt during selection (at most current and immediately previous rows). The workflow view consumes the immutable cached projection. Explicit terminal loading/auditing performs archive I/O; canvas paint does not open files or start models. Pointer, keyboard, focus, text equivalent, readable zoom, pan/reset, evidence, cancel/close/reopen and stale-source behavior are qualified separately by the native procedure in [g1-protocol.md](g1-protocol.md). Old material/carrier/generic-field inspection remains available.

Contract classes: coordinated in-process Rust types; versioned persisted profiles. No external pressure-v1 protocol, numerical formula, stage order or supported physical domain changes. Architecture remains Session/numerical owners → recording owner → cached native view; no second recorder, process supervisor, registry or solver state is introduced.
