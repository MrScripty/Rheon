# Prospective verification and acceptance contract

These criteria are **prospective**, fixed by the plan commit before any new production evaluation. They are targets, not results. Failure requires a retained diagnostic and method/envelope decision; thresholds cannot be silently changed after observing output. The original audit protocol/results remain immutable. Slice admission freezes exact formulas, geometry sources/hashes, compiler/runtime, method coefficients and executable commands in a source protocol before execution; missing method-specific dt constants are formulation gates, not permission to guess.

Each run records exact source and native executable hashes, SI material properties/temperature, initial/boundary conditions, input mesh bytes/transforms/units, seed/order, resolution/support, requested/actual dt, solver tolerances, actual commands/exit codes and raw fields. Retain summary and raw data outside Git with hashes in a compact committed manifest. Match time and gauge when comparing. Separate roundoff/iteration, quadrature/clipping, temporal, spatial and measurement uncertainty. If uncertainty is larger than the target, the result is unresolved, never pass. Two refinement ratios alone suggest an order; use three levels and report pairwise orders and finest error.

## Replacement contract gates

At each stage, subgraph and native-family level test: correct native candidate; nonfinite/range/shape/unit-version/operator mismatch; unsupported geometry/boundary; wrong actual shortened dt; wrong input generation; plausible but wrong field; cancellation before/after candidate and before commit; provider error, budget exhaustion and runtime termination. Use a divergence-free wrong dynamics fixture to show invariant gates alone do not establish accuracy. All invalid candidates must be refused, accepted state/time/history unchanged, fallback run from identical input only when declared compatible. Stateful fixture must prove prepare/abort restores numerical history/RNG, with disposable prepared state and infallible local adoption after all fallible work; otherwise refuse it. Inject prepare failure, abort failure and uncertain external commit; uncertain state must terminate/invalidate the provider until reconstructed from accepted history. In-process unpreemptible hang is outside hard deadline guarantee; external process tests exercise current supervisor timeout and cleanup semantics.

Classical baseline substitution must reproduce the native baseline within declared precision/solver tolerance over 100 intervals, with exact source/provider and reconstruction identities. Subgraph fixtures must expose required intermediate witnesses or host-recomputable full residuals. Whole-family fixtures use their native state; no implicit conversion. Transfers, if admitted, use analytic constant/linear velocity on translated/rotated particle clouds and grids: relative mass/momentum defect ≤1e-12 for binary64 closed-domain cases, positive mass, separately measured energy/work and reconstruction convergence (target order ≥0.9). This is not a guarantee of exact energy or reversibility. Learned accuracy admission needs retained actual model/runtime/weights and independent in-envelope/out-of-envelope comparisons; missing assets block that model qualification only.

## Clipped initialization and mesh admission

Use .3 m cube in 1 m liquid, known solid volume .027 m³; rotations 0/17/31/45° and translations 0/.25/.5/.75 lattice spacing on each axis. At 8/16/32/64 source cells per metre compare clipped volume/mass against independent analytic convex clipping and adaptive volume bounds. Target relative removed-volume error ≤.5% at finest resolution, every result enclosed by reported quadrature uncertainty, finest uncertainty ≤.1% of solid volume and decreasing. For an exactly polyhedral clipper, require error within its propagated roundoff bound rather than deliberately allowing .5%. No mass renormalization. Every nonempty representative is independently in admitted fluid; disconnected intersections split/refuse. Invalid winding/nonmanifold/open/self-intersecting/degenerate/nonfinite transforms and ambiguous units are refused where volume semantics need them. Two-sided collision-only surfaces are a distinct supported type and cannot masquerade as volumetric hydrodynamic walls.

Retain meshes and exact transforms; include submerged, free-surface-intersecting, oblique, curved and thin obstacles. Imported mesh results must match direct analytic primitive semantics within declared geometry uncertainty. Refinement must resolve smallest admitted feature; below-envelope geometry gives explicit refusal/diagnostic, not a universal collision claim.

## Capillarity, work and later moving geometry

Gravity-free 3D water drops R=.01/.02/.04 m, 16/32/64 cells across diameter (or matched particle spacing), sigma frozen. Target finest Laplace jump error ≤2%, spurious max speed ≤1e-4 m/s over one capillary time sqrt(rho*R³/sigma), decreasing with refinement; relative mass drift ≤1e-10 grid /1e-12 fixed particles. Compare curvature and pressure independently. Small-amplitude capillary waves use wavelength .01 m, amplitude 1e-5 m, 32/64/128 points/wavelength; measured frequency relative error ≤2%, damping ≤5% versus the appropriate finite/deep-depth viscous dispersion relation fixed before run. The dispersion/measurement fitting method is a required slice input, not an interchangeable posthoc formula. Contact-angle physics remains outside this drop/wave scope.

Stationary/translated prescribed planar wall tests account separately for fluid kinetic change, body/source work, viscosity, boundary traction work, collision impulse/loss and numerical residual. Ledger closure ≤1e-8 of a declared nonzero characteristic energy (also report absolute J); zero wall speed gives zero wall mechanical work. Moving geometry additionally advects constant velocity/volume through translated/rotated mesh motion with exact swept-volume/GCL balance ≤1e-10 relative and no unexplained momentum. Coupled body momentum/energy tests are a distinct later admission; unavailable support stays refused.

## Experimental validation gate

Retain independent MARIN or comparable primary experiment samples, apparatus geometry, gauge volume/area, timing/gate release/filtering, repeated-run spread and measurement/digitization uncertainty with data rights/source hashes. Freeze observation mapping and comparison windows before simulation. Target numerical discretization uncertainty below half experimental uncertainty for compared quantities; report pressure/height time series, peak timing/amplitude and interval coverage. Do not invent a universal 5% physical acceptance without the observed uncertainty. Scientific reviewer sets and commits the case-specific agreement criterion from those data before evaluation. Without those inputs V1 remains blocked, while all preceding code/numerical verification can proceed.
