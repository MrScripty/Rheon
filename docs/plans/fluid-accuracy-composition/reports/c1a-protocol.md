## Closed contracts

`ReplacementContract` selects pressure v1, existing sealed-MAC projection, whole sealed MAC or whole particle preview. Only pressure-v1 selection constructs a `PressureStageV1` borrowing the caller's existing `ProviderWorkspace`; all other well-formed selections return typed `ReplacementUnavailable` without touching workspace or calling providers/callbacks. This does not advertise replacement support for unavailable variants.

The pressure adapter delegates the actual `PressureRequest`, settings, optional existing `PressureProvider` and cancellation directly to `ProviderWorkspace::solve`. Successful `QualifiedPressureV1` borrows workspace pressure immutably and owns the unchanged ProviderReport; the borrow prevents another solve while that view is used. This means existing host-qualified pressure only, not corrected f32 velocity, Session publication, new metadata admission, native generation authority, physical accuracy or provider hidden-state rollback. Metadata remains descriptive and old candidate/fallback/settings/error semantics remain unchanged. Do not add validation that silently changes pressure-v1 behavior (including path-specific iteration-limit handling).

`NativeSession` is a closed borrowed enum over existing mutable `SimulationSession` and `MaterialSession`. Requests distinguish MAC `LiquidStepInputs`/`ProviderStepWorkspace` from particle `MaterialStepControls`; callbacks distinguish real MAC stage from a particle cancellation poll, without invented stages. Each request supplies expected caller-declared SessionIdentity (run id and source revision) and generation; compare family, identity, then generation against the actual owner before any native invocation/callback/workspace use. Identity guards detect wrong declared source, not authenticity or cryptographic full-state identity. Candidate/input-digest contracts outside existing pressure v1 remain deferred to B/C.

MAC baseline delegates `step_with_pressure_provider(..., None, ...)`; particle preview delegates `MaterialSession::step`. Preserve native deadline, cancellation, errors, actual shortened dt, native reports and publication semantics. Snapshot variants wrap original borrowed SessionSnapshot/MaterialSnapshot; no field conversion, copied accepted history or independent clock/quota. Particle preview stays visibly preview; this selects no particle method. `TransferOperator` names versioned MAC→particle and particle→MAC operations; `require_transfer` always returns typed unavailable. Wrong-family requests cannot trigger implicit transfer. Whole/subgraph/stateful candidates are not callable in C1-A.
