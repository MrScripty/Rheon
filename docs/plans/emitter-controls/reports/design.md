# Composed-design admission

Applicable: emitter parameters cross shared numerical, recording and desktop boundaries.
Produced artifact: one shared emitter control/sampling owner, consumed by carrier
forcing, particle births and native preview; existing run/session capture retains it.
Authority: existing RotatingCylinderEmitter and transactional owners; no parallel
emitter schema or turbulence state machine. UI edits the same fields used by physics.
State: immutable per-call controls, original center plus absolute time motion,
stateless seed sampling; accepted particle credits and clocks retain their owner.
Change path: add defaulted fields and shared helpers, update only emission consumers,
retain source records; public exhaustive struct literals need new fields or ..Default.
Failure: validation/geometry/time/cap/cancellation errors preserve accepted owners;
noise draws never mutate a generator or consume a sequence on rejection.
Boundary: spatial/temporal inlet noise, not a turbulence closure, collision shape,
pressure solver replacement or whole-process memory/performance promise.
Consumers: particle liquid/gas, legacy carrier, MaterialSession, desktop requests.
Removal/replacement: turbulence sampler can be replaced only with a recorded model
version change; UI and consumers do not reimplement it. Preserved pressure mode owns
compatibility defaults. Tests observe actual source evolution and accepted controls.
Evidence: defaults/native equivalence, field sample bounds/replay, rotated emissions,
step/clock/refusal/cancellation tests, headless egui control/overlay tests and strict
feature builds. Native graphics hardware cannot be inferred from headless checks.
