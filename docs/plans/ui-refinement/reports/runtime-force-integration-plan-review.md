## Source ownership and implementation shape

The admitted minimal Inspector region is recorder begin/record interfaces and
their pure construction helpers only. Preserve existing reload/selected-step,
error, identity, limit, finish and reader owners. Do not copy separate Inspector
projection/archive work or edit core recording/solver/configured Session owners.
Add the small exhaustive difference-label match in `run_sets/source.rs` to the
exact write set: current native labels match every existing `SpecDifference`.
No comparison layout redesign is necessary. Update the canonical active milestone
and its superseded interface-preflight wording to match this actual authorization.

Keep additive Inspector wrappers delegating legacy calls through None. Rebuild the
actual legacy header with its existing identity/provenance, apply the expected
optional force binding once, then retain the existing complete header equality
check. Both constructor and accepted publication paths use canonical wrappers.
Do not append bytes from the draft to accepted records. Core `require_fields`
already rejects absent/mismatched accepted custody; retain that failure behavior
and the accepted-but-unrecorded error distinction. Terminal recording, cancellation
and publication uncertainty stay owned by the current loop/recorder.

Native carrier selects the existing source/emitter force adapter and maps its
existing step result; particle material selects its canonical force adapter with
the original emitter/config/cancel policy. None follows the exact old branch.
Some(empty) uses explicit force metadata even though its physical field is empty.
Do not alter dt shortening/retry, source schedule, gravity, density conversion,
force evaluation, projection or thread ownership. Configured/provider/Session,
transport and free-surface combinations explicitly refuse authored requests;
disabled/zero fields are still authored metadata, not a way around eligibility.
