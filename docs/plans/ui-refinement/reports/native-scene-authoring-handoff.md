## Idle procedure: no numerical/model execution

1. Launch normally without --collision-run or any automatic workload option. At
   1250×820 and900×650,100% and150%, open Scene. At narrow logical width the setup
   drawer gives way to Scene, retaining the same top run/status/Cancel owner.
   Hide/reopen Scene; verify setup values and selection survive and viewport stays
   usable. Status details must remain reachable. Do not start a simulation.
2. Add Directional, Radial and Vortex via Add force. Check immediate selection,
   selected properties/name, units m/s² versus N/m³, direction/signed strength,
   metre positions, degree orientation, Global/Sphere/Box support/falloff and
   [start,end) seconds. Rename and edit; ensure values persist when switching rows.
   Unit selection deliberately reinterprets authored numbers; it does not invent
   an acceleration-to-density conversion. Gravity stays additive.
3. Set radius0 or invalid times, confirm visible validation. Correct them. Toggle
   Enabled, remove objects, and verify selection is cleared on deletion without
   another object becoming its edit target. With any authored object present,
   verify Run and independent lab/AI launch affordances are disabled with a reason.
   No authored-force numerical execution is part of this procedure.
4. Retained/Draft switching requires only an existing separately approved immutable
   retained fixture. Otherwise mark it unavailable. Do not create a run to test it.
   Draft must hide retained fluid/particle probes and preserve history/index;
   Retained must use frozen geometry and show unavailable authored-force metadata
   rather than the current draft. Check selected step/track remains unchanged.
5. Likewise model import/replacement can use an existing separately approved idle
   mesh fixture only. Otherwise report this native gap. No mesh/recording file
   modifications or solver run. Check accepted model row/properties, replacement
   clearing and original recording files unchanged. ID exhaustion is pure-test
   covered, not a reason to launch/import repeated fixtures.
6. For timeline playback use an existing separately approved retained fixture;
   never generate one by running a solver. Check bounded speed focus/edit, invalid
   text feedback,0.1–4× clamp, Up/Down, track popup, step/scrub and report wrapping.
   Source probes cover literal UI states; they do not replace this native check.
