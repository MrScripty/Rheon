A local discussion aid for the minimum initial-domain brush and multi-material voxel capability. Numerical work, UI behavior and acceptance evidence are still proposed.

Observed numerical gap

Existing liquid fractions can be transported while carrier inertia still uses one constant density. Viscosity also accepts a single constant value.

Spatial material IDs need a new voxel coupling path: material properties, interface transport and pressure must participate in the same accepted state.

Proposed first physical model

The fixed Water/Air reference pair: two incompressible, immiscible materials with fixed positive density and Newtonian viscosity, sharing one velocity and pressure field in a fully occupied, sealed box.

Gas cells are occupied material with mass. This model has no compressible gas EOS. Heat, phase change, GPU work and portals remain separate.

Proposed path from a stroke to a retained result

1

Author the draft

Round brush edits binary material IDs on the voxel lattice. A slice provides explicit interior access.

AddRemoveReplace

One completed stroke creates one atomic undo entry.

2

Validate and freeze

Check bounds, materials, budgets and full occupancy. Vacuum holes produce an actionable launch refusal.

Binary ID → fraction 0 or 1. The other material fills the complementary fraction.

Freeze geometry, material properties, initial input and method identity before launch.

3

Advance two-fluid MAC state

1. Conservative phase and matched momentum fluxes
2. Variable viscosity
3. Gravity
4. Variable-density pressure projection

This order keeps viscosity from modifying the gravity predictor in hydrostatic rest.

Accept all coupled fields together or preserve the preceding state.

4

Inspect retained materials

Display both materials and their interface fractions with the captured run identity.

Partial fractions represent interface coverage. They do not imply a miscible-mixture or phase-change model.

Later draft edits cannot change this run or its recorded initial state.

Scope choices awaiting parent review

  • Full occupancy: this first model refuses evolving vacuum or a liquid–vacuum free surface. A deliberate gas fill can occupy the surrounding region.
  • Incompressible gas approximation: gas has distinct density and viscosity, while pressure enforces incompressibility. Real gas compression requires a different model.
  • No surface tension: capillary forces and their interface-pressure effects are excluded from the proposed first model.

These are proposed limitations, not previously accepted user requirements. The canonical plan owns decisions, milestones and admission status.
