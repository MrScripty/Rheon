# Bounded public controller qualification prototype

One fixed pressure_state/nonconstant/forward case, h=0.00078125, acceleration
(0.0625,-0.125,0.03125), stamp id 131, original accepted prefix version 1.
The original initial and accepted publications are bound by the inherited
selected-capture packet. A native first public call must reproduce that prefix
bitwise. The two original source copies preserve every controller correction,
Jacobi/linear solve, threshold, planar/third/combined-work and publication gate.
Only the two extra diagnostic post-window equation observations are disabled;
ordinary native Newton traces remain enabled and do not change acceptance.

The reference owner is cloned once at a time through test-only Clone derives
on the existing fixed-topology fitted and translated owners. The candidate uses
the same complete cloned state, settings, pressure and clock, with one borrowed
fixed ChartWorkspace. There are at most two simultaneous test owners: original
prefix and active clone. Their native reservations remain separate and counted.
Snapshots and stage counters are fixed test-harness diagnostics, never retained
arithmetic tails or accepted-state authority. No growing trajectory history.

The 106-bit scalar source is byte-identical to the accepted E1 policy. The same
private first chart solve hook is used, with unchanged native geometry and full
downstream recomputation. Existing coordinates reconstruction supplies accepted
z into the chart workspace before each public call. No duplicate coefficient
extraction or new high-precision buffer is added. Slots are reset on every
solve; retry reconstructs from the unchanged accepted state. Native seed and
all other solves stay unchanged. No production file is committed with this hook.

The prototype and policy must be committed/pushed before compilation. Install
only the archived test includes and Clone derives with prepare.py; compile in
the dedicated target under the frozen flags. Run only scalar, type layout and
baseline conformance. Independently check scalar probes and the original native
fixed public-call refusal. Establish the NEW binary's simultaneous additional
bound, including changed caller frames and outgoing jumps, before permission
to run research_public_candidate_and_controls. The old 65,456-byte certificate
does not apply. Stop on an exceeded/unproved 65,536-byte cap; never enlarge it.

If qualified, run exactly one main candidate public call. It may publish only
its isolated owner after all ordinary gates pass. Run cancellation controls at
the twelve fixed stage indexes, skipping/reporting indexes not reached by that
same call; each reached stage gets one cancellation and one retry on that same
case from a fresh verified clone. Preserve all accepted fields on cancellation
or rejection; retry must reproduce the full-call result/state bitwise. No
parameter/case search, terminal-candidate override, tolerance change, changed
loading or production adoption. If the call refuses, fixed-candidate success
remains a different result. Controller and lifecycle qualification is not
claimed until those actual tests pass. Restore all production bytes afterward.
